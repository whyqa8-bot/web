# Primacarts WebView

Aplikasi Android WebView untuk https://primacarts.com/ dengan bottom navigation.

## Build otomatis

Push ke `main` akan menghasilkan Debug APK di GitHub Actions > Artifacts.

Push tag `v1.0.0` untuk membuat Release APK dan GitHub Release:

```bash
git tag v1.0.0
git push origin v1.0.0
```
